Hermes Agent＋Telegram＋ChatGPT：小學生也懂的完整圖解

每個工具在做什麼、為什麼要拆開，以及組合之後還能做哪些事？ 金霸研究編輯部 · 2026 年 9 月 13 日 · 約 8 分鐘閱讀

Hermes Agent、Telegram 和 ChatGPT 整合在一起時，名詞很多、設定也不少。不過先不要管 API、OAuth 或 Gateway，只要記住一句話。

Telegram 是嘴巴和耳朵，ChatGPT／Codex 是大腦，Hermes Agent 是會記事情、拿工具並真正動手的機器人管家。

實際上還有一個常被忽略的角色：伺服器是機器人的家與身體。Hermes 必須在電腦、VPS 或雲端環境中運作，才能持續收訊息、保存資料與執行排程。

先認識五位主角

T

Telegram：對講機

讓你從手機送出文字、語音、照片與檔案，也負責把結果顯示回來；它自己不會思考。

H

Hermes Agent：管家

辨認主人、記住對話、安排步驟、選擇工具、執行任務，最後把成果送回正確的聊天室。

AI

ChatGPT／Codex：大腦

理解自然語言、推理與規劃下一步。但只有大腦不會自動知道該去哪裡拿檔案或把結果送給誰。

V

伺服器：家與身體

讓 Hermes 有地方運作與保存設定。它可以是自己的電腦、便宜 VPS，或能閒置休眠的雲端環境。

＋

Skills／Tools：工具箱

搜尋、瀏覽器、程式執行、檔案、圖片、語音與排程，讓管家不只會說，也能真正完成工作。

一則訊息怎麼走完全程？

假設你在 Telegram 對機器人說：「每天早上七點整理 AI 新聞給我。」

你傳出需求
Telegram把訊息送走
Hermes辨識、記憶、規劃
模型＋工具思考並執行
Telegram收到成果

Hermes 的 Messaging Gateway 是連接 Telegram、Discord、Slack 等平台的背景程序，負責每個聊天室的 Session、排程工作與結果傳遞。Telegram Bot API 則是 Telegram 提供給開發者收發 Bot 訊息的 HTTP 介面。

每個工具實際負責什麼？

元件小學生比喻實際職責
Telegram對講機接收文字、語音、圖片與檔案，顯示回覆。
Telegram Bot對講機號碼讓 Hermes 可以透過 Telegram 的介面收發訊息。
Hermes Gateway管家門口接收訊息、驗證使用者、找到相對應的對話。
Hermes Agent機器人管家維持記憶、規劃工作、呼叫模型與選用工具。
ChatGPT／Codex大腦理解語言、推理與產生下一步，但不獨自管理 Telegram。
Skills／Tools工具箱搜尋、操作瀏覽器、執行程式、處理檔案與建立排程。
電腦／VPS管家的家讓 Hermes 持續運作並保存設定、記憶與工作檔案。

最容易搞錯：ChatGPT 不等於 Hermes

ChatGPT／Codex 模型可以思考，但通常不會自己知道訊息從哪個 Telegram 使用者而來、上一次對話存在哪裡、有哪些工具可以使用、哪些動作需要核准，以及完成後該回覆到哪個聊天室。這些工作由 Hermes 負責。

模型提供智慧；Hermes 把智慧組織成一位可以長期工作的 Agent。

Hermes 使用 OpenAI 的兩條路

路線一：ChatGPT OAuth／OpenAI Codex

透過裝置登入連接 ChatGPT 或 Codex 訂閱，讓 Hermes 使用 Codex 模型。這不是把 ChatGPT 網頁裝進 Telegram，而是授權 Hermes 使用模型服務。

路線二：OpenAI API

設定 OpenAI API Key，由 Hermes 呼叫 OpenAI API。這條路和 ChatGPT 消費者產品是不同的連接及使用方式。

Hermes 官方目前確認支援 ChatGPT OAuth，但哪些 ChatGPT 方案符合資格、使用量如何計入 Codex 限額，文件尚未完整說明。因此不應直接宣稱「買 ChatGPT Plus 就能讓 Hermes 無限制使用」。

為什麼故意拆成這麼多環節？

因為每個零件可以獨立替換：Telegram 可以改成 Discord 或 Slack；OpenAI 可以換成其他模型供應商或自架模型；換伺服器不必重做 Telegram Bot；要增加能力，只需要加入新的 Skill、Tool 或 MCP。

拆開看起來比較複雜，長期反而更容易維護。汽車也不會把方向盤、引擎和輪胎焊成一顆大鐵球——雖然整合度很高，但大概只能拿來滾下山。

組合後可以做什麼？

  • 私人助理
    記事、提醒、行程與資料整理。
  • 每日情報站
    新聞、金融、競品與社群摘要。
  • 遠端工程師
    從 Telegram 指派修改、測試與 Git 工作。
  • 研究助理
    搜尋來源、比較資料並整理報告。
  • 語音助理
    傳語音，自動轉錄、執行與回覆。
  • 文件工廠
    產生報告、圖片、簡報與試算表。
  • 家庭中控
    連接 Home Assistant 查詢或控制設備。
  • 定時巡邏
    監看網站或服務，異常時主動通知。

最後一塊不能省：安全

這不是普通聊天機器人

Telegram 接上 Hermes 後，使用者可能是在遠端操作一台能讀檔案、上網與執行工具的電腦。Bot Token 必須保密，並應設定允許名單或配對機制、區分管理員與一般使用者、讓危險指令需要核准，以及使用隔離環境與最小權限。

Hermes 官方提供使用者 allowlist、一次性配對碼、管理員／一般使用者分級、危險命令核准與容器隔離。若機器人具有終端機權限，切勿為了方便直接開放給所有陌生人。

Telegram 讓你隨時找得到它；ChatGPT／Codex 讓它聽得懂你；Hermes 讓它記得住、會用工具，而且真的把事情做完。
