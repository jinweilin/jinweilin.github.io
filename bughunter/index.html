Claude-BugHunter 懶人包

給已經在用 Claude Code、想學合法資安檢查的開發者與資安學習者：兩步裝好一套由 681 份公開揭露報告整理出來的獵洞技能包。

看攻擊方打法，是為了在自己有授權的系統先找到洞、修好它，懂攻擊為了防守。

本頁前提：你已安裝並能使用 Claude Code。

這是什麼

它是一套給 Claude Code 用的技能包（skill bundle）。裝好之後，你只要用白話描述想測什麼，相關技能會自動載入，不用記技能名稱、不用手動搬檔案。內容分四層：

  • 思考：獵洞方法論與紅隊思維紀律，先想清楚再動手。
  • 獵網頁：58 個獵洞技能，來自 681 份公開揭露的 HackerOne 報告，含偵測模式、payload、繞過表與串鏈模板。
  • 打邊界：企業平台攻擊鏈（M365/Entra、Okta、vCenter、SSL VPN、雲端 IAM 等），多為 2024–2026 的 CVE 鏈。
  • 交付：送出前的驗證關卡（7-Question Gate）、證據遮罩紀律與報告寫作。

先講邊界（裝之前先看）

  • 只能用在自己的，或有書面授權的資產，限自己的系統、漏洞獎勵計畫範圍內。
  • 沒授權掃別人的系統，是違法。
  • 工具內建驗證關卡：指向未驗證的第三方目標時，triage-validation 的 7-Question Gate 會先問這個資產在不在授權範圍內。
  • 它只看對外攻擊面，也不保證跑完：Anthropic 模型有即時資安防護，連授權範圍內的工作也可能被模型中途擋下；做授權滲透／獵洞的人可申請官方的 Cyber Verification Program 調整防護（連結在文末）。

安裝（兩步）

在 Claude Code 裡依序輸入這兩行（原文照貼，不要改）：

/plugin marketplace add elementalsouls/Claude-BugHunter
/plugin install claude-bughunter@elementalsouls

裝好後，83 個技能與 15 個指令會進到專屬命名空間 claude-bughunter: 之下，跟著外掛版本更新，不會把檔案複製進你的 ~/.claude/。實際技能與指令數量以你裝完後的實測為準。

備案：複製安裝（不用外掛系統，或想固定版本）

git clone https://github.com/elementalsouls/Claude-BugHunter.git
cd Claude-BugHunter
# macOS / Linux
bash scripts/install.sh
# Windows (PowerShell)
pwsh ./scripts/install.ps1

複製安裝會把技能與指令放進 ~/.claude/，並附帶 cbh CLI 與 hunt 任務腳手架；外掛安裝則沒有後兩者（cbh 可另外用 pipx 裝）。同一套 SKILL.md 格式也能裝到 OpenCode、Codex CLI、Hermes、AntiGravity 等其他 agent 工具，細節見官方 multi-harness 指南。

怎麼用

裝好後打開 Claude Code，用白話講你在測什麼、在授權範圍內的哪個目標，技能就會自動載入。官方示意範例：

Testing acme.com — an in-scope HackerOne target.
Run recon and rank the surface.

（上為官方 README 的示意對話，實際輸出依你的目標與授權範圍而定。）常用的 slash commands 包含 /hunt、/recon、/report 等共 15 個。

範圍與限定（先講清楚）

涵蓋：對外攻擊面 — Web 應用與 API、SaaS、GraphQL／OAuth／JWT、企業平台（M365、Okta、SharePoint、vCenter、SSL VPN）、雲端設定錯誤與取得憑證後的提權、偵察與 OSINT、平台與客戶報告。

不涵蓋（官方明言是設計取捨，不是缺陷）：內網 Active Directory 攻擊（Kerberoasting、DCSync 等）、C2 框架、後滲透／持久化／橫向移動、規避偵測（AMSI／EDR bypass）、iOS 滲透／硬體／RF／ICS、二進位與核心利用；官方另明文排除 0-day 武器化、惡意軟體開發與大規模目標掃描。如果你做的是內網紅隊，這套在那些階段幫不上忙。

其他限定：看攻擊方打法，是為了在自己有授權的系統先找到洞、修好它 — 懂攻擊是為了防守。模型可能中途擋下部分請求（見邊界段），這不是這套工具的故障。
