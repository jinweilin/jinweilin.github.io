CLI-Anything 懶人包：讓 AI 不點滑鼠，直接下指令操作軟體

先講結論：這是香港大學做的開源專案，它幫一個個軟體做好「指令遙控器」加一份 AI 看的說明書（SKILL.md），AI 照著下指令就能操作軟體，不必看著螢幕慢慢點滑鼠。這一頁有安裝方式、完整支援清單、我們自己跑過的實測，還有裝之前一定要看的安全邊界。

這是什麼

CLI-Anything 是一套「把軟體變成 AI 能直接操作」的工具產生器。它用 7 階段自動流水線去研究一個軟體，產出一組指令工具（CLI）加上一份 SKILL.md 說明書；AI agent 讀了說明書，就能用打指令的方式操作那個軟體。

為什麼要這樣做？現在 AI 操作軟體有兩條路：一條是看著螢幕點滑鼠（GUI agent），一條是直接下指令（CLI）。兩條路各有擅場、會並存——點滑鼠通用但慢又容易點錯，下指令快而精準，但前提是軟體得先有指令介面。CLI-Anything 做的就是把這個前提補上。官方標語是「Making ALL Software Agent-Native」，口號講的是 ALL，實際進度就是下面那份 60 多個的清單，兩件事分開看。

官方展示過的示範包括：FreeCAD 蓋好奇號探測車、Blender 做軌道中繼無人機、Draw.io 畫 HTTPS 握手圖、Slay the Spire II 遊戲自動化、VideoCaptioner 自動上字幕、ArcGIS Pro 製圖。

快速開始（走 CLI-Hub 安裝）

已經生成好的指令工具統一放在 CLI-Hub 上，裝法就兩步（原文照貼，不要改）：

pip install cli-anything-hub

cli-hub install <name>

第二行的 <name> 換成你要的軟體名稱，例如我們實測用的就是 cli-hub install drawio（名稱以 CLI-Hub 上架名為準）。裝好後，每個工具會以 cli-anything-軟體名 的形式出現在你的系統裡，可以直接在終端機下指令，也能交給 Claude Code 等 agent 透過 SKILL.md 來操作。官方 README 的 Quick Start 另有 Claude Code、Cursor、Codex 等 agent 平台的外掛接法，想把整套產生器接進自己的 agent，請照官方文件走。

我們實測了：10 句指令，Draw.io 畫出 HTTPS 握手圖

影片裡那張圖不是官方示範截圖，是我們自己跑的。實測紀錄如下，指令全文照貼，你可以自己複驗：

  • 日期與環境：2026-11-21，在我們的 Linux VM 上（repo 快照加獨立 venv），工具是 Draw.io harness 的 cli-anything-drawio
  • 做了什麼：建專案 1 句、加圖形 2 句（瀏覽器、伺服器）、加連接線 7 句，共 10 句指令
  • 結果：10 句全部執行成功，總耗時 1.05 秒，產出 Draw.io 檔案：上方是瀏覽器、下方是伺服器，中間 7 條帶標籤的連接線（SYN、SYN-ACK、ACK、ClientHello、ServerHello + Certificate、Finished、Encrypted Data）
cli-anything-drawio --json project new --width 850 --height 1100 -o handshake-raw.drawio
cli-anything-drawio --json --project handshake-raw.drawio shape add rounded --id browser -l "瀏覽器 Browser" --x 315 --y 40 -w 220 -h 64
cli-anything-drawio --json --project handshake-raw.drawio shape add rectangle --id server -l "伺服器 Server" --x 315 --y 990 -w 220 -h 64
cli-anything-drawio --json --project handshake-raw.drawio connect add browser server --id msg1 -l "SYN"
cli-anything-drawio --json --project handshake-raw.drawio connect add server browser --id msg2 -l "SYN-ACK"
cli-anything-drawio --json --project handshake-raw.drawio connect add browser server --id msg3 -l "ACK"
cli-anything-drawio --json --project handshake-raw.drawio connect add browser server --id msg4 -l "ClientHello"
cli-anything-drawio --json --project handshake-raw.drawio connect add server browser --id msg5 -l "ServerHello + Certificate"
cli-anything-drawio --json --project handshake-raw.drawio connect add browser server --id msg6 -l "Finished"
cli-anything-drawio --json --project handshake-raw.drawio connect add browser server --id msg7 -l "Encrypted Data"

誠實註記兩件小事：一、harness 產出的連接線預設會疊在一起，我們事後只把每條線的連接點位置沿著圖形寬度分散開，圖形、標籤和連接關係都是這 10 句指令產出的，內容沒有改。二、我們第一次嘗試時旗標用錯、10 句全數失敗，上面是第二次乾淨重跑的紀錄——所以你第一次跑失敗也別意外，先看錯誤訊息再重來。

安全邊界（裝之前先看）

這一套工具的本質，是讓 AI 自主組裝指令、直接操作你電腦上的真檔案。方便是真的，風險也是真的，先講清楚再裝。

官方有做的防護（出自官方 SECURITY.md，它有正式的威脅模型文件）：

  • 官方自承首要風險是 prompt injection：AI 讀到不可信的輸入時，可能被誘導組裝並執行不該執行的指令——這是官方自己寫在威脅模型第一位的
  • 參數白名單驗證：指令參數要通過白名單檢查，不是 AI 想塞什麼都行
  • 路徑正規化：擋掉用相對路徑繞去不該碰的目錄
  • 金鑰檔權限收緊為 0o600（只有檔案擁有者能讀寫）
  • 程式碼禁止用 shell=True 執行指令，XML 解析改用 defusedxml 防 XXE 類攻擊

還是存在的風險（官方有防護，不代表可以無人看管）：

  • 供應鏈沒有簽章把關：CLI-Hub 是從 GitHub 和第三方來源拉程式碼下來執行，沒有簽章或雜湊鎖定，來源那一端被動手腳，你這邊不會收到警告
  • 它操作的是真檔案：不是沙盒玩具，AI 下錯指令，改掉或刪掉的就是你的真實檔案
  • 清單裡有高權限工具：JumpServer（堡壘機）、Zoom、Mailchimp 這類會碰帳號與金鑰的工具都在清單裡，這種一旦被誘導操作，出事的不是一張圖，是帳號本身

我們的安全檢查表（影片裡講的四條，照著做）：

  • 只裝官方 Hub 的，不要來路不明的來源
  • 裝之前先看清：這個工具會碰哪些軟體、哪些檔案
  • 重要檔案先備份，再讓 AI 動手
  • 碰帳號、金鑰的，不要放手讓 AI 自己跑，人要在旁邊看
